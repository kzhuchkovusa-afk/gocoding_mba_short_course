### Быстрый способ:
1. Откройте файл `mobile-test.html` в браузере
2. Измените размер окна браузера
3. Прокрутите вниз - там теперь **ТРИ тестовых секции**:
   - Progressive Pricing Structure
   - Benefits Cards
   - Location Options (НОВОЕ!)
4. Внизу справа увидите индикатор размера экрана
5. Он меняет цвет в зависимости от размера:
   - 🟢 Зелёный = Desktop (>768px)
   - 🟠 Оранжевый = Mobile (481-768px)
   - 🔴 Красный = Small Mobile (<480px)

### На реальном телефоне:
1. Откройте `index.html` на iPhone или Android
2. Прокрутите до секции с ценами
3. Проверьте, что всё читается легко
