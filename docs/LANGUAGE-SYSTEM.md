# Система переключения языков MBA for Kids

## ✅ Что уже работает:

1. **Переключатель языков** в навигации (RU/EN с флагами)
2. **JSON файлы с переводами** для русского и английского
3. **Автоматическое сохранение** выбранного языка в localStorage
4. **Плавная анимация** при переключении
5. **Адаптивный дизайн** - на мобильных переключатель в правом нижнем углу
6. **Переведены основные блоки**: навигация, hero-секция, статистика

## 🎯 Как это работает:

### UX/UI особенности:

1. **Переключатель в навигации (десктоп)**:
   - Стильные кнопки с флагами 🇷🇺 🇺🇸
   - Активная кнопка подсвечивается
   - Hover эффект для интерактивности

2. **Переключатель на мобильных**:
   - Фиксированная позиция справа внизу
   - Только флаги (без текста для экономии места)
   - Всегда доступен при скролле

3. **Сохранение выбора**:
   - Язык сохраняется в localStorage
   - При следующем визите откроется тот же язык
   - Нет необходимости выбирать заново

## 📝 Как добавить переводы для остальных секций:

### Шаг 1: Добавьте data-i18n атрибут к HTML элементу

```html
<!-- Было: -->
<h2>Что беспокоит родителей</h2>

<!-- Стало: -->
<h2 data-i18n="problem.title">Что беспокоит родителей</h2>
```

### Шаг 2: Убедитесь что перевод есть в JSON файлах

Проверьте, что в `js/translations-ru.json` и `js/translations-en.json` есть соответствующий ключ:

```json
{
  "problem": {
    "title": "Что беспокоит родителей подростков"  // в ru
    "title": "What worries parents of teenagers"   // в en
  }
}
```

### Шаг 3: Для вложенного HTML (с тегами внутри)

```html
<h1 data-i18n="hero.title">
    Ваш ребёнок запустит свой первый 
    <span class="gradient-text">бизнес-проект</span>
</h1>
```

В JSON используйте HTML теги:
```json
{
  "hero": {
    "title": "Ваш ребёнок запустит свой первый <span class='gradient-text'>бизнес-проект</span>"
  }
}
```

## 💡 API для разработчиков:

## ⚙️ Технические детали:

1. **Хранение**: `localStorage.getItem('mba-language')`
2. **По умолчанию**: Русский язык ('ru')
3. **Формат JSON**: UTF-8, валидный JSON
4. **Загрузка**: Асинхронная через fetch API
5. **Анимация**: Плавное изменение opacity при переключении

## 🐛 Устранение неполадок:

### Перевод не отображается?
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что JSON файлы валидны
3. Проверьте путь к файлам переводов
4. Убедитесь, что data-i18n совпадает с ключом в JSON

### Переключатель не работает?
1. Проверьте, что `language.js` загружается до `script.js`
2. Откройте консоль и проверьте ошибки
3. Проверьте наличие класса `lang-btn` на кнопках

### Язык не сохраняется?
1. Проверьте работу localStorage в браузере
2. Убедитесь, что не работаете в режиме приватного просмотра
3. Очистите кэш браузера
