# 🚀 Как опубликовать сайт MBA for Kids

## Быстрый старт (2 минуты)

### ✅ Публикация на платформе

1. **Нажмите вкладку "Publish"** в верхней части интерфейса
2. **Нажмите кнопку "Publish"**
3. **Скопируйте ссылку** - ваш сайт уже в интернете!

**Это всё!** 🎉 Сайт работает с HTTPS и готов к использованию.

---

## 🌐 Подключение своего домена (необязательно)

### Если хотите свой домен типа `mbaforkids.com`:

#### Шаг 1: Купите домен
- **Namecheap.com** - $10-12/год
- **GoDaddy.com** - $12-15/год  
- **Google Domains** - $12/год

#### Шаг 2: Используйте Netlify (бесплатно)

**A) Зарегистрируйтесь:**
1. Идите на **netlify.com**
2. Создайте аккаунт (бесплатно)
3. Нажмите **"Add new site"**

**B) Загрузите проект:**
1. Скачайте все файлы проекта
2. Перетащите в окно Netlify
3. Сайт опубликован!

**C) Подключите домен:**
1. В Netlify: **Domain settings** → **Add custom domain**
2. Введите свой домен
3. Netlify покажет DNS настройки

**D) Настройте DNS:**
В панели регистратора домена добавьте:
```
Type     Host    Value
A        @       75.2.60.5
CNAME    www     ваш-сайт.netlify.app
```

Готово через 1-2 часа! ✅

## 📞 Используйте ссылку для рекламы

Даже без своего домена, ссылка от Netlify/платформы **полноценная**:

✅ Подходит для Facebook Ads  
✅ Можно отправлять в WhatsApp  
✅ Работает в Google Ads  
✅ Размещается в соцсетях  

**Пример:** `https://mba-for-kids.netlify.app`

### Самые частые вопросы:

**Q: Где кнопка Publish?**

**Q: Нужно ли покупать домен?**

**Q: Как обновить сайт после изменений?**  
A: Просто нажмите Publish снова

**Q: Сколько стоит хостинг?**  
A: $0 на Netlify/Vercel/GitHub Pages
