## 🧠 Стратегия конверсии (3 уровня)

### 🔝 Верх (Alert):
**СРОЧНОСТЬ** → "Действуйте сейчас, чтобы получить ставку $350/месяц"

### 🎯 Середина (Cards + Breakdown):
**ЦЕННОСТЬ** → "$17.50/час — в 3-12 раз дешевле альтернатив"

### ✅ Низ (Average Student):
**ДОКАЗАТЕЛЬСТВО** → "Даже средние ученики достигают всего этого"

**Результат = Тройная убеждающая система:**
1. **Дефицит** (alert) → страх упустить
2. **Логика** (breakdown) → разумное решение
3. **Социальное доказательство** (outcomes) → работает для других

| Элемент | Психологический эффект | Результат |

| "Один навык" | Уникальная ценность | Мы комплексные, а не узкие |
