## Technical Implementation

### Files Modified

1. **js/translations-ru.json** - Added new translation keys:
   - `phases` section (complete phase descriptions, buttons)
   - `benefitsDetails` section (detailed benefit card content)
   - `bonuses` section (updated bonus cards, buttons, CTA)
   - `schedule` section (week-by-week breakdown)
   - `valueBreakdown` section (average student benefits)

2. **js/language.js** - Extended `applyManualTranslations()` function:
   - Added Phases Section translation logic
   - Added Benefits Details translation logic
   - Added Bonuses Section updates (values, toggle buttons)
   - Added Schedule Section translation
   - Added Value Breakdown translation

3. **js/script.js** - Updated button handlers:
   - Step toggle buttons now use `window.getTranslation('phases.seeDetails')`
   - Benefit toggle buttons use `window.getTranslation('phases.hideDetails')`
   - Bonus toggle buttons use `window.getTranslation('bonuses.learnMore')` / `window.getTranslation('bonuses.showLess')`

### How It Works

1. **Initial Page Load:**
   - Language.js loads appropriate translation JSON file based on localStorage
   - Calls `applyManualTranslations()` to replace all text

2. **Language Switch:**
   - User clicks EN/RU button
   - New translation file loads
   - `applyManualTranslations()` re-runs
   - All text updates instantly

3. **Dynamic Button Text:**
   - Toggle buttons check current language on click
   - Use `window.getTranslation()` to get appropriate text
   - Ensures consistency after language switching

## Future Maintenance

To add new content with translations:

1. **Add English text to HTML**
2. **Add translation key to `js/translations-ru.json`**
3. **Add selector logic to `applyManualTranslations()` in `js/language.js`**
4. **Test both EN and RU versions**

Example:
```javascript
// In applyManualTranslations()
const newSection = document.querySelector('.new-section');
if (newSection && t.newSection) {
    const title = newSection.querySelector('h2');
    if (title) title.textContent = t.newSection.title;
}
```
